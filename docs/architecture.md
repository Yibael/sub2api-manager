# 技术与页面设计

## 已确认的技术栈

- React + TypeScript + Vite
- TanStack Router、TanStack Query、TanStack Form + Zod
- shadcn/ui（Radix Nova）+ Tailwind CSS 4
- Bun + Elysia；不直接从浏览器查询 sub2api
- vite-plugin-pwa / Workbox
- Vitest；页面交互通过 computer use 检查，不引入 Playwright 测试套件

## 页面

| 路由 | 内容 |
| --- | --- |
| `/` | 汇总指标、已关注账号、额度、状态、手动刷新 |
| `/accounts` | 账号目录、搜索、筛选、Pin 与排序、订阅编辑 |
| `/accounts/:id` | 运行状态、今日统计、完整额度、周期消费 |

## 查询与共享缓存

浏览器 → 同源 Elysia API → sub2api。Admin Key 只由服务端读取。公开响应按字段白名单生成，不回传账号 credentials、任意 extra 或上游错误正文。

后端没有轮询计时器、Cron、后台刷新或自动重试任务。每次请求按以下顺序处理：

1. 相同键已有进行中的请求：共用该 Promise。
2. 上次成功查询完成后尚未达到刷新间隔：直接返回缓存，不附加缓存命中提示。
3. 失败退避尚未结束：返回上次数据及失败原因。
4. 否则执行一次查询并保存成功结果；失败只更新错误和下次允许查询的时间。

缓存到期不会触发任何操作。停止前端请求后，后端不会再开启新的刷新轮次。已进入服务端的一轮有限请求可以完成；单次 HTTP 请求（含排队）20 秒超时，多步骤查询有 30 秒总信号。共享请求不绑定到某一个设备的断连，避免设备 A 取消时误伤正在等待的设备 B。

刷新间隔按上次成功完成时间计算，缓存命中不续期。改变间隔保留数据与进行中的请求，失败退避也不会因修改间隔而被绕过。普通手动刷新不突破后端间隔；上游额度始终 `force=false`。

| 通道 | 默认 | 缓存粒度 |
| --- | --- | --- |
| 账号目录 | 60 秒 | 当前实例目录 |
| 账号状态 | 5 秒 | 账号 ID |
| 今日标准价 / 账号费用 / 请求 / Token | 5 秒 | 上游统计日期 + 账号 ID |
| 上游额度与窗口费用 | 30 秒 | 账号 ID |
| 今日与周期消费 | 15 秒 | 账号 ID + 起止日期 + 时区 + Admin 开关 |

每个 Monitor 只绑定一个实例与凭据。更换凭据重启进程后自然隔离缓存。今日统计的日期边界使用 `SUB2API_TIMEZONE`，必须与上游的自然日口径一致。消费使用用户明确配置的时区。

缓存按账号复用，设备选择 `[1, 2]` 与 `[2, 3]` 时，账号 2 不会重复查询。批量读取为尚未缓存的账号构建请求；旧服务端不支持额度批次时，回退为单账号查询，并记住该能力。普通 OpenAI / Anthropic API Key 不查询 OAuth 额度。

单进程内存缓存，单缓存最多 5000 个键；仅按需清理旧键，不驱逐正在执行或仍处于冷却的键。当前不支持多副本之间共享缓存，生产部署使用一个应用进程。若以后扩容，需要把缓存、请求协调和会话迁移到共享存储。

## 数据归属

- 服务端：Admin Key、应用访问密码、内存会话、共享数据缓存、持久化刷新间隔。
- 当前设备：Pin 顺序、订阅价格与续费日、统计偏好、主题、金额隐藏状态。
- Service Worker：只预缓存静态应用资源；不缓存 `/api` 响应或 Admin 数据。
- 开发预览：独立示例数据源，不访问真实上游，独立实例 ID 和刷新设置文件。用户界面不显示模式标识。

## 统计约定

界面统一使用标准用量、消费、额度、周期、成本。今日标准用量使用 `standard_cost`，概览汇总全部已关注账号；今日消费和周期消费统一使用 `total_actual_cost`，跟随统计时区和 Admin 开关。`cost` 与 `user_cost` 不作为另一套消费指标展示。7日额度估算仍采用原窗口算法，仅在 OpenAI OAuth 账号中展示。缺失和失败不填零。

只有已关注且完整配置价格、续费日的 OAuth 账号计入概览和统计汇总；账号详情可以独立查看自身周期；未配置订阅及 API Key 账号也可通过 `/spending/today` 查询今日消费，该接口与周期查询共享同一个按账号、日期范围、时区和 Admin 开关隔离的缓存。订阅价格可为零，月价不按天摊销。不同账号各自分割订阅周期，短月取月末，后续月份恢复原续费日。展示周期终点为下次续费日前一天，实际请求只查询到今天。

排除 Admin 时分页读取当前 Admin 名单，先查询同范围 Admin 小计，再查询总计，以 Decimal 相减；不是原子结算快照。必要结果缺失时不显示部分汇总。两个消费范围分别处理错误。货币符号只控制显示，不执行换汇。

## iOS 与离线

目标兼容 Safari / iOS 16.4+，Vite 显式构建到 Safari 16.4。包含主屏幕图标、standalone Manifest、安全区、动态视口、44px 主要触控区域、16px 移动输入、底部导航、减少动画偏好。

页面隐藏时停止前端刷新调度并取消前端请求，返回前台恢复按需请求。关闭再离线启动可加载应用外壳并显示连接错误；不持久化受保护的账号快照。当前会话断网可继续显示内存数据并提示离线。新版本就绪时提示用户更新，不自动打断表单。

没有实现后台监控、Web Push、跨设备配置同步或账号管理写操作。

## 产品文案

页面标题不添加英文眉题或营销副标题。指标卡仅显示名称、数值和图标；不添加底部解释行。账号平台、类型、周期、重置时间和数据异常属于必要信息，应保留。刷新调度、缓存、凭据存储等实现说明仅出现在开发文档中，不进入页面、页脚或保存提示。安装操作、表单校验以及会替换用户配置的操作保留简短提示。
