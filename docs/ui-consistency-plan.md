# 页面设计一致性规划

日期：2026-10-04
状态：已实施并完成本地样例预览与回归验证。

## 目标与基准

沿用现有的中性色、浅背景、白色卡片、Lucide 线性图标和 shadcn/ui Radix Nova。以概览页的卡片结构和已有共享组件为基准，统一页面层级、排版、操作和反馈。

统一规则按信息的作用制定：页面标题、模块标题、卡片标题、字段标签、辅助文字分别保持一致。数据页保留适合比较的布局，设置页保留适合阅读和编辑的宽度。

## 检查结果

检查了页面与共享组件源码，以及本地样例预览中的概览、账号目录、统计、账号详情和设置；统计页另检查了 768px 和 1024px 视口。分组预览的 fixture 未提供分组数据，正常数据布局目前仅由源码检查，实施时需要补齐样例验证。

| 优先级 | 问题 | 证据 | 收敛方向 |
| --- | --- | --- | --- |
| 高 | 刷新按钮存在两套尺寸和反馈 | 旧 `RefreshButton` 固定 76×36px、显示文字或倒计时；榜单、权益和订阅使用 40/44px 图标按钮；旧按钮有 300ms 收尾反馈，局部按钮各自实现加载 | 扩展一个共享刷新组件，提供文字、图标两种明确模式，统一尺寸、图标、忙碌反馈和无障碍名称 |
| 高 | 加载骨架未同步页面改版 | `RouteSkeleton` 仍使用“账号管理”“消费统计”，统计页仍为顶部刷新和旧指标顺序留位，只包含一张榜单；`/groups` 落入概览布局 | 按实际路由重建骨架；标题、模块顺序、列结构和操作占位与完成状态一致 |
| 高 | 中等宽度下榜单标题被挤压 | 768px 出现侧栏后，消费榜的总消费标签和金额被挤成上下两行，而模型榜仍同行；标题操作区按视口 `sm` 断点提前横排 | 依据卡片可用宽度换行，窄卡片将时间范围与刷新放到下一行 |
| 中 | 同级标题、标签和辅助文字使用不同字号 | 概览模块标题使用 `.section-heading`，统计页手写 `text-sm font-medium`；旧 CSS 中标签为 9–11px，新增 Field/说明多为 14px | 定义少量字体层级，让同级内容共享规则，提升手机辅助文字可读性 |
| 中 | 目录和明细的间距、信息排序分别定义 | 账号目录、分组目录、消费明细各自设置内边距、分隔线和操作区；设置首页使用旧行样式，子页使用 Field | 统一卡片内边距、行间距、元数据和操作位置，保留符合用途的表格与列表形式 |
| 中 | 空状态表达不一致 | 无关注账号使用 Empty，无订阅使用 Alert，部分详情和 Passkey 空状态使用普通段落 | 无数据使用 Empty，查询失败与提醒使用 Alert；按页面、卡片、行内场景选择合适尺寸 |

## 统一规范（已采用）

### 排版与间距

| 内容 | 桌面 | 手机 |
| --- | --- | --- |
| 页面标题 | 26px，600 字重 | 24px，600 字重 |
| 模块与卡片标题 | 16px，600 字重 | 16px，600 字重 |
| 子分组标题、字段标签 | 14px，500 字重 | 14px，500 字重 |
| 正文、表格 | 14px | 14px |
| 辅助说明、日期、查询时间 | 12px | 12px |
| 汇总指标 | 32px | 28px |
| 卡片内局部指标 | 22px | 20px |

- 间距使用 4/8/12/16/20/24/32px；页面主要模块之间统一 24px。
- 普通卡片内边距桌面 24px、手机 20px；汇总指标卡使用明确的紧凑模式，内边距 16px。
- 圆角、边框、阴影和颜色由共享 token 与组件维护。
- 金额、计数、百分比和倒计时使用等宽数字；金额与 Credits 继续各自使用原有精度规则。
- 长名称、长模型名和长数值定义截断或换行规则，完整内容保持可查看。

### 操作与状态

- 保存和确认使用主按钮，查询和编辑使用 outline，导航和轻量辅助操作使用 ghost，危险动作使用 destructive。
- 图标刷新统一放在所属标题或工具栏右侧；需要说明查询范围的入口提供清晰名称。倒计时作为辅助信息，保持按钮的操作含义可辨识。
- 手机按钮热区至少 44px；自动用卡继续由开关自身触发，前方标题和说明为展示内容。
- 范围与单选筛选复用 SegmentedControl；平台数量较多时复用 Select；主题选择保留图标形式。
- 首次加载使用对应结构的骨架；后续查询保留现有内容，在所属操作位置显示加载状态并禁用重复点击。
- 无数据、未知值、读取失败和更新失败分别表达；未知数值继续显示 `—`。
- 更新提示继续使用设置导航 badge 和内联更新卡片。

## 实施顺序

### 1. 收敛基础规则与共享组件

- 在 `src/index.css` 集中整理字体、间距、卡片和按钮规则，移除相互覆盖的旧样式。
- 扩展 PageHeading，统一返回入口和操作位置；添加共享 SectionHeading，支持标题、说明、图标、数量和操作。
- 扩展 RefreshButton，统一文字/图标模式、加载和无障碍反馈。
- 收敛 detail-metrics 与 spending-values 的标签、数值和间距；复用已有 Card、Field、Badge、Empty、Alert。

### 2. 逐页应用

1. 概览和统计：统一标题、指标、模块间距和刷新入口；修正榜单在窄卡片下的排版。
2. 账号详情：统一权益、邀请、自动用卡、运行状态与周期卡片的层级；保留每项独立查询时间。
3. 账号与分组目录：统一搜索区、计数、状态、分隔线和操作位置；检查桌面表格与手机列表。
4. 设置及子页：统一设置行与 Field 的文字层级、保存区域和说明密度。
5. 登录、抽屉与确认框：复用同一套排版、按钮与错误反馈规范。

### 3. 同步加载状态并验证

- 更新各路由骨架，与实际标题、模块顺序、表格列和按钮占位保持一致。
- 检查首次加载、查询中、未知值、空数据、错误和保留旧结果等状态。
- 在 375/390px 手机、768px 侧栏临界宽度、1024px 和宽桌面检查对齐、换行、热区与遮挡；检查浅色、深色和减少动态效果。
- 使用本地样例数据核对单次手动刷新对应的请求；运行构建、lint 和必要的既有回归测试。
- 更新架构文档中的页面设计规范，并提供主要页面的前后截图。

## 已确认的交互约束

- 消费榜、模型榜、订阅与成本分别刷新；统计页保持局部操作。
- 重置卡与 Credits 共用 quota 查询，邀请独立查询；详情进入时读取一次，后续由用户手动查询。
- 每项权益保留自己的查询时间，轮询账号状态继续保留已经展示的权益结果。
- 自动用卡以查询到的上游配置初始化，初始化期间保持加载状态，并沿用现有变更确认流程。
- 样式调整复用现有查询处理函数、缓存和统计口径；组件挂载和条件渲染需核对请求次数。

## 验收标准

- 相同层级的标题、标签、说明、状态与操作在各页面采用相同规则。
- 页面从骨架过渡到内容时，标题和模块顺序保持一致，操作位置稳定。
- 手机及侧栏临界宽度没有横向溢出、相互挤压或导航遮挡。
- 局部刷新只触发原有对应查询，权益读取次数符合已确认行为。
- 长名称、精确 Credits、金额隐藏及错误状态均可正确展示。

## 实施结果

- 集中整理应用样式与几何 token，移除旧页面中相互覆盖的尺寸定义；复用现有组件与主题，没有增加依赖。
- 增加共享 `PageHeading` / `SectionHeading`，收敛刷新、空状态、目录、指标、设置 Field、抽屉与确认框的排版和反馈。
- 榜单、分组、权益和页面网格按各自容器宽度响应，支持侧栏临界宽度；大金额允许换行，长模型名保留完整名称提示。
- 补齐统计双榜单、分组目录与各设置子页骨架，标题、模块顺序和操作占位同步真实页面。
- 保留已有查询与写入流程，统计三模块各自刷新，自动用卡仅由 switch 触发。

## 验证记录

- 本地 fixture 检查了概览、账号与分组目录、账号详情、统计、设置及设置子页，覆盖浅色、深色、金额隐藏、长名称与大金额。
- 浏览器 viewport 覆盖存在缩放，实际 DOM 内容宽度以读取值为准；已检查约 360 / 394px 手机、776px 侧栏临界宽度和 1096px 桌面，并额外检查 288px 窄屏。手机刷新按钮热区为 44px，页面与榜单表格未出现横向溢出。
- 统计首次读取展示正确的双榜单骨架，没有顶部刷新占位；自动用卡配置延迟读取时显示加载状态和未知阈值，完成后显示上游配置，点击文字区域不会触发变更。
- 模拟配置读取失败时，自动用卡显示未知状态、未知阈值和错误提示，没有显示为关闭或提供可操作开关；测试结束后恢复正常样例。新构建就绪时仍通过设置导航 badge 与内联更新卡片提示，主动更新后加载最新资源。
- 权益进入详情时 quota / referrals 各读取一次；经过状态轮询后两项 GET 计数保持不变。手动 quota 与 referrals 各只增加对应一次 POST 和对应的 Sub2API 刷新调用。
- 模型榜一次手动刷新仅增加模型榜请求，消费榜请求计数保持不变；账号状态与消费的原有自动轮询继续生效。
- 206 项既有测试全部通过；构建、lint 与 `git diff --check` 通过。减少动态效果的统一 CSS 规则继续覆盖过渡、分段动画和骨架。
